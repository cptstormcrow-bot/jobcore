C. Time Off edit-in-modal

C1. Calendar section is new-request only

Expected: Time Off screen: calendar section is titled "Request time off" and shows no Reason field, Save, Delete or "Cancel edit" inline — it is new-request only.

C2. Tapping a date opens the request modal and Submit creates it

Expected: Tap a date in the calendar → modal opens titled "Request time off"; enter a reason, tap Submit → request appears under "My requests" and modal closes.

C3. Tapping an upcoming request opens Edit modal prefilled

Expected: Under "My requests", tap an upcoming request you created → modal opens titled "Edit time off" with its dates pre-selected in the modal calendar and the reason pre-filled.

C4. Save applies edits

Expected: In the edit modal, change the date range in the modal calendar, edit the reason, tap Save → modal closes and the row shows the new dates/reason.

C5. Delete removes the request

Expected: Re-open an upcoming request, tap Delete → the request disappears from "My requests" and the modal closes.

C6. Cancel discards changes

Expected: Open an edit modal, then tap Cancel → modal closes, no changes saved, no row remains highlighted/selected.

C7. Overlay tap / Android back behaves like Cancel

Expected: Open an edit modal, then tap the dark overlay outside the sheet (or Android back) → same as Cancel.

C8. Admin-added requests are read-only

Expected: Tap an admin-added (blackout) request → modal shows "Added by your admin", calendar and reason are disabled, and the only button is Close.

C9. Background calendar disabled while modal is open

Expected: While the modal is open, the calendar behind it is disabled (tapping it does nothing).

C10. Modal scrolls to keep action buttons reachable

Expected: On a small screen or with the keyboard open, the modal sheet scrolls so Save/Delete/Cancel remain reachable.

C11. Regression: Jobs calendar week view

Expected: Jobs calendar week view still fits the screen width, week/month toggle, prev/next, Today all still work, and time-off dates are still red bold.
